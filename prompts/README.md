# Prompt sets

Prompt templates used to generate and judge the teaching plans reported
in the accompanying paper, reproduced verbatim from the internal
experiment scripts of the CLEAR implementation (file paths and line
ranges are given for each extract).

- `prompt_sets.md` - single-turn generation, multi-turn generation, and judgment prompts
- `runtime_configuration.md` - completion caps, prompt budgets, and decoding settings as run

Conditions map to the paper as follows: `B0` = DMU, `B1` = PCMU, `B2` = ELMU,
`B3` = MPP, `CLEAR` = CLEAR-Mem. The public `clear` core package does not
include the internal experiment scripts; these files are documentation
extracts, not runnable experiment code.
